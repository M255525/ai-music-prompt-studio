操作手冊

音樂提示詞產生器把曲風、情緒與歌詞方向的設定，組成適合 Suno 自訂模式或 Gemini 對話協作使用的音樂提示詞。填一次曲風與歌詞設定，兩個分頁共用；可以直接複製組成結果，也可以串接你自己的語言模型取得中英對照的完整版本。

Suno／Gemini 分頁差異

Suno
Suno（自訂模式）

產生 Suno 自訂模式（Custom Mode）可直接貼上的三段內容：Style of Music（風格標籤）、Lyrics（含 [Verse]／[Chorus] 等段落標記的歌詞）、Exclude Styles（排除風格，選填）。

GM
Gemini（作詞／製作建議協作）

Gemini 本身不是音樂生成模型，這個分頁組成的是一句自然語言請求，貼進 Gemini 對話框，請它幫你寫歌詞草稿或給製作建議，你再自行把結果帶去 Suno 之類的工具生成音樂。

操作步驟

  1. 先套用一個「範例」快速看懂欄位怎麼填，或直接從空白開始
  2. 填「歌曲主題」（必填），並視需要勾選曲風、情緒氛圍、速度、人聲風格、語言、樂器編制、歌曲段落——這些設定 Suno／Gemini 兩個分頁共用，只需要填一次
  3. 「歌詞內容或主題」可以只填一句歌詞方向，或直接貼上你已經寫好的完整歌詞（用空行分段）；只填方向時，Suno 分頁只會產生段落骨架
  4. 在最上方選一個分頁（Suno／Gemini）
  5. 按「🔧 組成提示詞」，下方會出現對應的輸出區塊，可個別按「複製」或整包按「複製全部」
  6. 若想取得潤飾過或完整補上歌詞的版本，展開「送給 AI 優化」面板的「API 連線設定」填入自己的金鑰，按「🚀 送給 AI 優化」
  7. 滿意的結果可以在下方「已儲存的提示詞」取名儲存，之後隨時載回來或下載成 .txt 檔
切換分頁不會清掉曲風與歌詞設定——這些欄位是兩個分頁共用的；但每個分頁各自的「組成結果」與「AI 優化結果」會分開保留。
「歌曲段落」的勾選順序不影響輸出順序——Suno 分頁一律依 Intro → Verse → Pre-Chorus → Chorus → Bridge → Outro 的固定順序排列你勾選的段落。

「組成提示詞」與「送給 AI 優化」有什麼不同

🔧 組成提示詞是純前端的關鍵字組裝，不需要 API 金鑰、不會連網：把你填的曲風／情緒／樂器等標籤（已經是對應的英文片語）組合成 Suno 風格標籤，歌詞欄位若只是主題方向則產生段落骨架（尚未有真正歌詞內容）。

🚀 送給 AI 優化會把曲風與歌詞設定送給你設定的語言模型：Suno 分頁會請 AI 潤飾風格標籤，若歌詞只是骨架就直接請 AI 用你選擇的語言寫出完整歌詞；Gemini 分頁會請 AI 產出中文＋English 雙語的歌詞草稿與製作建議。

如果只是想快速看一下標籤組合或骨架結構，用「組成提示詞」就好；想要完整可用的歌詞內容，建議走「送給 AI 優化」。

已儲存的提示詞

「已儲存的提示詞」是一個留在瀏覽器裡的紀錄清單，按「儲存」不會下載任何檔案，只是把目前分頁已組成的內容（連同 AI 優化結果，若有）存成一筆有名字的紀錄。

  1. 在儲存名稱欄位打一個好記的名字（留白會自動取名），按「儲存」
  2. 清單中每一筆紀錄可以「載入」（會自動切換回對應的分頁並覆蓋欄位）、「複製」、「下載 .txt」或「刪除」
  3. 取相同名字再按一次「儲存」會詢問是否要覆蓋既有紀錄
「儲存」＝存進這台瀏覽器的清單；「下載 .txt」才會真的產生一個檔案到你的下載資料夾。兩者是分開的動作。

送給 AI 優化（選用，需自備 API 金鑰）

填好曲風與歌詞設定之後，可以直接在本工具呼叫你自己的語言模型 API，取得針對目前分頁優化過的中英對照版本。

  1. 展開「API 連線設定」，選擇服務商（Claude／OpenAI／Gemini／OpenRouter），填入你自己申請的 API 金鑰；模型欄有預設值，也可以自行改成你想用的模型 ID
  2. 按「🚀 送給 AI 優化」
  3. 優化結果會顯示在「AI 優化結果」區塊，可按「複製 AI 結果」使用
API 金鑰要自己到各服務商網站申請，使用時依你與該服務商的方案計費，本工具不會向你收費，也不會經手你的金鑰——金鑰只存在你這台電腦的瀏覽器，且直接連到服務商官方 API，不會經過本工具以外的任何伺服器。
