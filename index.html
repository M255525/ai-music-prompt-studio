一句話靈感，組出可用的音樂提示詞

填一次曲風、情緒與歌詞方向，Suno／Gemini 兩個分頁共用——組成 Suno 自訂模式可直接貼上的標籤與歌詞不需金鑰，或串接你自己的語言模型，取得中英對照的完整版本。

✎曲風與歌詞設定

以下設定 Suno／Gemini 兩個分頁共用；只有下方輸出區塊的組裝格式會依分頁不同。

只填主題方向時，下方「Lyrics」只會產生段落骨架；已貼上完整歌詞時，會依你勾選的段落標記自動分段。若「人聲風格」選純音樂無歌聲、或「語言」選無歌詞，這欄會被忽略，改為產生製作建議。

音樂品質面的排除，例如過度重複、混音渾濁。

曲風/元素面的排除，例如不要重金屬、不要饒舌；沒列到的可以在下方文字框自行補充。

▦目標

AI送給 AI 優化（中英對照）

串接你自己的語言模型 API，把曲風與歌詞設定送出，取得針對目前分頁優化過的版本——Suno 分頁會潤飾風格標籤並視情況直接寫出完整歌詞；Gemini 分頁會產出中文＋English 雙語的歌詞草稿與製作建議。

API 連線設定

金鑰只存在這台電腦的瀏覽器（localStorage），不會送到本工具以外的任何地方；按下「送給 AI 優化」時，曲風與歌詞設定會直接傳送給你選擇的服務商 API。請勿在共用電腦上填寫金鑰。

REC已儲存的提示詞

把目前這份提示詞（含 AI 優化結果，若有）存成一筆有名字的紀錄，留在這台瀏覽器裡；需要檔案再從清單裡個別下載。

使用警語
  • 本工具產生的是「音樂提示詞」，實際生成的音樂內容與品質仍取決於 Suno 或你使用的音樂生成服務，請自行檢查是否符合該服務的條款與政策。
  • 本工具不會也不建議輸入任何「模仿特定真實歌手／樂團音色」的描述——這類要求可能違反目標服務條款或衍生著作權疑慮，刻意未提供此類選項。
  • 請勿在任何欄位輸入真實個資、機密資料或受著作權保護的他人內容——欄位資料只存在你自己瀏覽器的 localStorage，不會上傳到任何伺服器，但送出給 AI 服務後的隱私仍由該服務條款規範。
  • 「送給 AI 優化」需要你自行填入 API 金鑰，該金鑰只存在你的瀏覽器，按下產生時會直接連線到你選擇的服務商，本工具不會經手或保存金鑰，也不會向你收取任何 API 費用——實際費用依你與該服務商的方案計算。
  • AI 產生的歌詞內容可能與既有著作雷同，發布或用於生成音樂前請自行查核；本工具與創作者不對後續生成的音樂內容負責。
